# 💰 FICON — Financial Controller

Aplikasi keuangan pribadi berbasis web. Lacak pengeluaran, pendapatan, dan tabungan bulanan dengan grafik interaktif.

## Fitur
- 📊 Dashboard dengan kalender live & grafik pengeluaran harian
- ➕ Tambah pengeluaran dengan kategori
- 💵 Input pendapatan per bulan
- 🏦 Tabungan bulanan otomatis
- 💎 Total tabungan kumulatif
- 💾 Data tersimpan di browser (localStorage)

## Deploy
Dibuat dengan HTML, CSS, dan JavaScript murni — tidak butuh server atau framework.
